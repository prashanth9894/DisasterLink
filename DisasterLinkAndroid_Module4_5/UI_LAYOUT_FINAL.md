# DisasterLink – Final Android UI Layout

This version follows the supplied mobile mockup as the visual reference while keeping the existing project functionality.

- Supplied Home artwork remains the Home hero background and is cropped for a portrait phone viewport.
- Dashboard screens use compact cards, metric tiles, two-column action tiles, and a bottom navigation bar.
- Citizen: Emergency History, Feedback, Raise Emergency, My Location and recent emergencies.
- Rescue: Assigned/Pending/Done metrics, task cards with assigned/start/end timestamps and task details.
- Authority: four separate command boxes, separate analytics metric cards, district analysis, department performance and Emergency Command Center.
- District-wise complaints and Department Performance open as dedicated screens instead of being mixed into one long page.
- Bluetooth/location requests continue through Android's native permission/settings flow when a dashboard opens.
- Feedback remains accessible at all times for a logged-in citizen.
- Existing SOS-without-login behavior is retained.
